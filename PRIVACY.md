# Wordtopia - Privacy Policy

Wordtopia is a student English-vocabulary learning app.

- Data we store: account email, display name, learning progress and push notification tokens.
- Email access: the app uses the Gmail API (gmail.send scope) only to send one-time verification codes to the user who requested a password reset. It does not read, list or store any mailbox content.
- We do not sell or share personal data with third parties.
- To request deletion of your data, contact the developer at phamkkua12345@gmail.com.
